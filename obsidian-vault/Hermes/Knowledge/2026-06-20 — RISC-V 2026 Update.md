## Summary

Annual RISC-V review covering the state of the open ISA in 2026. Key developments include Meta's acquisition of Rivos (Oct 2025) and Qualcomm's acquisition of Ventana Micro Systems (Dec 2025) — both signaling enterprise mainstreaming. RISC-V International achieved ISO/IEC PAS submitter status and released its first annual report.

Interview with CEO Andrea Gallo covers:
- **Automotive sector**: RISC-V as a single ISA from ECU to zonal controller to central compute in software-defined vehicles, enabling multi-supplier strategy
- **AI native design**: vector extensions (RVV 1.0) and upcoming matrix extensions eliminate DMA/copy overhead — the same core runs control software, AI framework, and inference
- **RVA23 profile**: binary compatibility baseline ratified Oct 2024, enabling OS vendors to target a single build that runs on all RVA23-compliant silicon

New hardware spotlighted:
- **Spacemit K3**: 8× X100 cores @ 2.4GHz, 8× A100 AI cores, 60 TOPS, Imagination GPU — shipping in Milk-V Jupiter 2 (Pico-ITX, up to 32GB LPDDR5, 10GbE SFP+)
- **Tenstorrent Ascalon X**: RVA23 server core targeting Arm Neoverse, with Atlantis dev board H2 2026
- **Alibaba T-Head Xuantie C950**: server-oriented RISC-V processor design (IP only)
- **DeepComputing Framework mainboard III**: RVA23-compliant mainboard for Framework 13 laptop

OS ecosystem: Ubuntu 26.04 LTS (first with RVA23 support), RHEL preview, Debian 13, Fedora, openSUSE, Arch Linux. Yocto 5.3 full RISC-V support. RISE project accelerating open-source RISC-V software.

## Takeaway

2026 is the year RISC-V transitions from microcontroller/embedded dominance to application processors. The RVA23 profile, combined with first-generation RVA23 silicon (Spacemit K3), enterprise acquisitions (Meta, Qualcomm), and full OS support (Ubuntu 26.04 LTS, RHEL, Debian 13), signals RISC-V is becoming a genuine third architecture alongside ARM and x86 — starting in automotive and edge AI, with data center ambitions via Tenstorrent and Alibaba. The $300-575 Milk-V Jupiter 2 brings desktop-class RISC-V to developers for the first time.
