## Key Findings

### Architecture Comparison (webtechie.be, Jan 2026)
- **ARM**: 1-15W, dominates mobile (99% smartphones) and SBCs, Apple M-series + AWS Graviton proving high-end viability
- **x86**: 10-65W, backward compatibility since 1985, Intel NUC discontinued 2023, LattePanda continuing with GPIO
- **RISC-V**: 1-20W, open standard, boards 2-3× slower than Pi 4 at same clock, but RVA23 changes the game
- Java support on all three: Adoptium builds for RISC-V (Java 17, 21, 25), Pi4J on ARM, full desktop/server on x86

### RISC-V SBC Benchmarks (RISC-V International, June 2025)
Five boards tested by ExplainingComputers:
1. Orange Pi RV2
2. Banana Pi BPI F3
3. Cyped Lite Pi 3A
4. Milk-V Jupiter (original)
5. VisionFive 2

Coverage: CPU/GPU/system benchmarks, software compatibility, storage speeds (eMMC ~950 MB/s read for VisionFive 2), power efficiency. Results available at Geeky Gadgets.

### Milk-V Jupiter 2 / Spacemit K3 — The Game Changer (LinuxGizmos, May 2026)
- **Processor**: SpacemiT K3 — 8× X100 RISC-V @ 2.4 GHz, dual RT24 real-time cores, RVA23 with RVV 1.0 (up to 1024-bit vectors)
- **AI**: 8× A100 cores, 60 TOPS, INT4/INT8/FP8/INT16/FP16/BF16 support
- **Memory**: Up to 32 GB LPDDR5 (dual 64-bit, 6400 MT/s)
- **Storage**: Onboard 256 GB UFS + M.2 M-Key 2280 NVMe
- **Networking**: 10GbE SFP+ + Gigabit RJ45 + Wi-Fi 6 + BT 5.2 + 4G/5G via SIM
- **Display**: 4K60 via USB-C DP Alt Mode + eDP 2560×1440@90Hz
- **GPU**: IMG BXM-4-64-MC1 (Vulkan 1.3, OpenCL 3.0)
- **Pricing**: $300 (8GB), $380 (16GB), $575 (32GB)
- **OS**: Ubuntu 26.04 LTS, Bianbu 3.0, OpenHarmony 6.0, Fedora
- **Key differentiator**: SFP+ 10GbE + AI 60 TOPS on RISC-V for the first time at this price point

### Current Limitations
- RISC-V boards still 2-3× slower than comparable ARM at same clock speed (less compiler optimization, fewer JVM intrinsics)
- GPU support remains lacking vs ARM
- Disk/RAM I/O underwhelming compared to x86 (per SystemCrafters forum consensus, May 2026)
- Most exciting hardware (Milk-V Jupiter 2) just entering pre-order phase

## Key Takeaways
1. RVA23 is the inflection point — binary compatibility enables OS vendors to target one build for all RISC-V application processors
2. Spacemit K3 + Milk-V Jupiter 2 at $300-575 is the first desktop-class RISC-V SBC with genuine AI/edge capability (60 TOPS)
3. 10GbE SFP+ on a $300 RISC-V board is unprecedented and opens server/edge networking use cases
4. RISC-V still 2-3× behind ARM on per-clock performance, but the gap is closing faster than many expected
5. For developers: the "Design Your RISC-V CPU Core" free course + Milk-V Jupiter 2 pre-orders + Ubuntu 26.04 LTS support make 2026 the first year RISC-V is practically accessible for serious experimentation
