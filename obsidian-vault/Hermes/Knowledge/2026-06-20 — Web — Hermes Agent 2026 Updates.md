## Panoramica Versioni 2026

Hermes Agent ha avuto un ciclo di rilascio intenso nel 2026, da v0.10.0 (17 marzo) a v0.17.0 (19 giugno).

### v0.17.0 "The Reach Release" (19 giugno)
- iMessage senza relay Mac
- Subagenti asincroni in background
- Image-to-image editing
- Automation blueprints
- Dashboard profile builder completo
- Skills Hub rinnovato
- WhatsApp Business API nativo
- Aggiornamento desktop: traduzione cinese, finestre di watch dei subagenti live, supporto tema VS Code

### Punti Chiave
- **198k stelle GitHub**, 35k fork, 245 contributor nella finestra dell'ultimo rilascio
- **Closed learning loop**: crea automaticamente skill riutilizzabili dopo task complessi, che si auto-migliorano nel tempo
- **40+ skill incluse**, **15+ piattaforme chat**, **6 backend di esecuzione**, **400+ modelli** supportati via Nous Portal

### Architettura
- Sistema di memoria persistente multi-livello
- Skills procedurali auto-generate
- Supporto multi-piattaforma (Telegram, Discord, WhatsApp, CLI, TUI, API)
- MCP (Model Context Protocol) nativo
- Sicurezza e sandboxing
- MLOps integrati
